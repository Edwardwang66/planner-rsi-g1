# Project page

Static page for the planner-RSI project. No build step.

- `index.html`: the page.
- `assets/`: figures copied from the project's outputs, and the final report PDF.

Preview locally:

```bash
python -m http.server 8765 --directory site
```

To publish with GitHub Pages, push the contents of this folder to a repository and enable Pages for its root (or deploy this folder from a larger repository with a Pages workflow).
